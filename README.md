# Frontend Mini Projects: Portfolio and Todo App

This repository contains two simple frontend projects created using **HTML**, **CSS**, and **JavaScript**.

---

## 📁 Folder Structure

### `/portfolio`

- A personal portfolio website that includes:
  - Homepage with name, intro, and profile picture
  - Project section with GitHub links
  - Contact section with a basic form
  - Clean and responsive layout



---

### `/todo`

- A fully functional todo list app featuring:
  - Add, delete, and mark tasks as complete
  - Data persistence with `localStorage`
  - Responsive and clean UI
